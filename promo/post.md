# Пост для канала

Картинка — `mietapp-card.png` (2160×2700, 4:5), текст идёт подписью к ней
одним сообщением.

**Отправить себе готовый пост:** `python promo/send.py` — придёт ровно в
том виде, в каком его увидит читатель, вместе с премиум-эмодзи. Дальше
его можно переслать в канал: значки и форматирование переживают
пересылку. Копировать разметку руками бесполезно — Telegram Desktop
вставит её обычным текстом.

Пересобрать картинку: `python promo/render.py` (нужен Chrome или Edge).

Значки берутся из `bot/emoji.py` — того же набора, который бот рисует в
расписании: пост и бот выглядят как одно целое. Если Telegram премиум-
эмодзи не примет, `send.py` сам отправит те же строки обычными.
